# 🚌 CloudBus Pass - Official Android App

Production Android Application for the CloudBus Transit System, connecting directly to the live cloud backend on Render.com (https://cloudbus-backend.onrender.com).

## 🚀 Features
- 🎫 **Live Bus Pass & Ticket Booking** with real-time seat availability
- 📱 **Digital QR Code Generation** for passenger passes
- 📄 **Official PDF Ticket Download**
- 🛡️ **Conductor QR Scanner & Ticket Verification Portal**
- 💬 **Live Passenger Support Chat Desk**
- 📊 **Real-time Admin Analytics & Management Dashboard**
